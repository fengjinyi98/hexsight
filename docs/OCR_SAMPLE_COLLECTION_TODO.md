## 采集规范

| 项目 | 规范 |
|---|---|
| 原图目录 | `docs/ocr_samples/` |
| 文件格式 | PNG |
| 命名建议 | `YYYYMMDD_round_scene_index.png` |
| 推荐例子 | `20260525_5-3_shop_001.png` |
| 保留要求 | 保留原始截图，避免裁剪、压缩、二次缩放 |
| 同步评测 | 新增样本后运行 `swift run HexSight --ocr-eval ../docs/ocr_samples` |
